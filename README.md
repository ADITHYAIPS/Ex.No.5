---

# AI Tool Required

* ChatGPT

---

# Explanation

## Types of Prompts

### 1. Naïve Prompt

A naïve prompt is broad, unclear, or minimally structured. It gives very little context or instruction to the AI model.

**Example:**
“Tell me about Artificial Intelligence.”

### 2. Basic Prompt

A basic prompt is clearer, more detailed, and structured. It provides instructions, context, format, or constraints to guide the AI toward a more accurate and useful response.

**Example:**
“Explain Artificial Intelligence in simple terms with real-world examples, advantages, disadvantages, and applications in healthcare and education.”

# Detailed Test Scenarios and Outputs

## Scenario 1: Creative Story Generation

### Naïve Prompt

> “Write a story.”

### Output

A short general story without clear theme, character depth, or direction.

### Basic Prompt

> “Write a 200-word science fiction story about a robot that learns human emotions while living with a family.”

### Output

A structured science fiction story with emotional development, characters, and a meaningful conclusion.

### Analysis

* **Quality:** Better in basic prompt.
* **Accuracy:** More aligned with user expectations.
* **Depth:** Included emotional and narrative detail.

---

## Scenario 2: Factual Question Answering

### Naïve Prompt

### Output

General information with limited structure.

### Basic Prompt

### Analysis

# Conclusion

The experiment proves that prompt engineering significantly affects AI-generated responses. Basic prompts provide:

* Better structure

Therefore, using clear and detailed prompts is the most effective way to obtain high-quality outputs from [ChatGPT](https://chatgpt.com?utm_source=chatgpt.com).

# Findings

1. Basic prompts consistently produced better outputs than naïve prompts.
2. Structured prompts improved:

   * Response quality
   * Accuracy
   * Relevance
   * Context understanding
3. Naïve prompts worked reasonably well only for simple or open-ended tasks.
4. Providing constraints such as:

   * Word count
   * Tone
   * Audience
   * Topic focus
     significantly improved the response quality.

# Conclusion

Therefore, using clear, structured, and detailed prompts is the most effective way to obtain high-quality outputs from [ChatGPT](https://chatgpt.com?utm_source=chatgpt.com).
